# Compact handoff

Create or update a handoff note at the user's requested location. If no file is requested, return the note in the response. Capture only:

- Goal and acceptance criteria.
- User constraints and decisions still in force.
- Current branch and relevant paths, when known.
- Completed changes and key supporting evidence.
- Checks run and their actual outcomes.
- Remaining work, blockers and the next concrete action.

Use exact identifiers and commands when needed for resumption. Link to source files instead of pasting large snippets. Omit secrets, repetitive history and abandoned approaches unless they explain an active constraint.

Distinguish facts from assumptions. On resumption, verify the current working tree and any stale evidence before acting. A handoff is context, not authorization for new external or destructive actions.
